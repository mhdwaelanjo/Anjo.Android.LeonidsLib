# Anjo.Android.LeonidsLib

---------------------------------
LeonidsLib SDK for .NET for Android (formerly Xamarin.Android) Binding Library - Wael Anjo
---------------------------------

Leonids is a particle system library that works with the standard Android UI.
You can download Leonids [Demo from Google Play](https://play.google.com/store/apps/details?id=com.plattysoft.leonids.examples&pli=1) to check out what can be done with it.
 
Getting Started : https://github.com/plattysoft/Leonids & https://plattysoft.github.io/Leonids/

Star on GitHub if this project helps you: https://github.com/mhdwaelanjo/Anjo.Android.LeonidsLib
